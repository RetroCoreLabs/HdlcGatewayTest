# API Reference

Generated from the XML documentation comments of the HdlcGatewayTest projects: Core (frames,
FCS, byte stuffing, control frames, the traffic test engine), Serial (serial and TCP
transports), Gateway (the sessions and roles behind each pane), Mcp (the MCP server and its
tools), Loopback (the `hdlc-loopback` command line) and App (the window). The tree on the left
lists every namespace, type and member.
